Privacy and usage

code.denniswu.org · HK Venue Seats. Last updated 4 October 2026.

In short: this site counts visits anonymously, on its own server. It sets no cookies, keeps no IP addresses or other personal data, and never records what you type or choose. The viewer also counts which venue is shown, by its id. The planner and the customiser keep nothing at all. By using the site, you agree to this anonymous counting.

What is counted

Every page of this site counts visits with GoatCounter, run on this site's own server (stats.denniswu.org). For each page view it records:

  • the page (its address on this site) and its title;
  • the venue whose seat list the viewer is showing (its id, such as ktt-aud);
  • the page you came from (referrer), if your browser sends it;
  • the type of browser and operating system, the screen size and the browser's language;
  • the country, looked up from your IP address, which is then discarded and never stored;
  • a temporary, anonymous visit identifier (not a cookie), so one visit is not counted twice.

It also counts which features are used, by name only: for example “downloaded CSV”, “category added”, “plan saved”. Apart from the venue's id, these names never include a value: no seats, prices, names, targets, nor the pit, seat types, parts of house or standing you choose in the viewer — nothing else you enter or select.

What is never collected

  • No cookies and no browser storage, for statistics or anything else.
  • No IP addresses are stored, by the statistics or by the web server's logs.
  • No names, email addresses, accounts or sign-ins.
  • Nothing you type or choose in the viewer, the planner or the customiser, apart from which venue the viewer is showing (see above).
  • No advertising or third-party tracking; nothing is shared with or sold to anyone.

The planner

The planner runs entirely in your browser. What you enter there (price categories, prices, targets, people's names, which seats you choose) is never sent to the server and never stored. It disappears when you close or reload the page, unless you save your plan as a file on your own device. When a plan holds people's names, the planner offers to protect the file with a passphrase (encrypted in your browser), or to leave the names out. The planner asks you to agree to these terms each time you open it, because it keeps no record that you did.

The customiser

The customiser runs entirely in your browser. The changes you make to a venue's seats are never sent to the server and never stored. They travel only in the page's link, in the part after “#”, which browsers never send to a server, and they disappear when you leave, unless you save them as a file on your own device. Usage statistics count which features are used, by name only (e.g. “change added”), never which seats. The customiser asks you to agree to these terms each time you open it.

Server logs

The web server keeps ordinary access and error logs, to keep the site running. They record the time, the page requested and the response, but not your IP address.
