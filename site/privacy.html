Privacy and usage

code.denniswu.org · HK Venue Seats. Last updated 26 September 2026.

In short: this site counts visits anonymously, on its own server. It sets no cookies, keeps no IP addresses or other personal data, and never records what you type or choose. The planner keeps nothing at all. By using the site, you agree to this anonymous counting.

What is counted

Every page of this site counts visits with GoatCounter, run on this site's own server (stats.denniswu.org). For each page view it records:

  • the page (its address on this site) and its title;
  • the page you came from (referrer), if your browser sends it;
  • the type of browser and operating system, the screen size and the browser's language;
  • the country, looked up from your IP address, which is then discarded and never stored;
  • a temporary, anonymous visit identifier (not a cookie), so one visit is not counted twice.

It also counts which features are used, by name only: for example “downloaded CSV”, “category added”, “plan downloaded”. These names never include any value: no seats, prices, names, targets or anything else you enter or select.

What is never collected

  • No cookies and no browser storage, for statistics or anything else.
  • No IP addresses are stored, by the statistics or by the web server's logs.
  • No names, email addresses, accounts or sign-ins.
  • Nothing you type or choose in the viewer or the planner.
  • No advertising or third-party tracking; nothing is shared with or sold to anyone.

The planner

The planner runs entirely in your browser. What you enter there (price categories, prices, targets, people's names, which seats you choose) is never sent to the server and never stored. It disappears when you close or reload the page, unless you download your plan, which saves a file on your own device. The planner asks you to agree to these terms each time you open it, because it keeps no record that you did.

Server logs

The web server keeps ordinary access and error logs, to keep the site running. They record the time, the page requested and the response, but not your IP address.
