Hong Kong Performing Arts Venues Seat Configuration

Seat configurations for Hong Kong's performing-arts venues, built as open data: every row, seat number and printed mark is read from the seating plans LCSD publishes, and each part of house and orchestra-pit option is checked against the venue's own totals. A viewer renders the data for each hall and counts the seats for any configuration, and an open-source planner lays out price categories, reserved seats and names in your browser, keeping nothing.

What it is

Facts, not drawings

For each hall: its parts of house, rows, seat numbers in blocks, and the marks the plan prints (wheelchair spaces, management seats, restricted sightline, limited legroom). No seat positions, images or copies of any plan.

Checked against LCSD

Every part of house is counted and must match the total LCSD prints; every orchestra-pit option must match LCSD's stated seats lost. The build fails otherwise.

A planner that keeps nothing

Take a configuration from the viewer into the planner: price categories, a ballpark gross and average ticket price, a simple gap analysis against your target, and names on seats. Everything stays in your browser; save your plan as a file on your own device.

A viewer for configurations

Choose a pit, which seat types to count and which parts of house are open; each option shows the seats it adds or removes. Download the seat list or your configuration as JSON or CSV.

Sources

  • Seating plans published by the Leisure and Cultural Services Department (LCSD), read directly.
  • Capacity statements on LCSD's own pages and technical-information sheets for each venue, quoted with URL and version.
  • Addresses and coordinates from LCSD's open data on DATA.GOV.HK.
  • Never ticketing or box-office data, and never seat maps compiled by others.

LCSD claims copyright in its plans and in compilations of data on its site (notice). This project publishes only facts about each hall and credits LCSD in every file. This is not legal advice.

Use the data

Each venue is one JSON file (schema hkperf-venue-seats/seatlist@0.3) with a CSV beside it (one line per seat), listed in data/index.json. The format and the counting rule are described in Data format, and how a venue is added in the repository's README.

Questions

Is this the venue's official seating plan?

No. The map is a schematic drawn from the seat list: rows centred, blocks side by side, seats in number order. It shows which seats exist, not where they physically sit. For the actual plan, use the version the venue publishes, linked beside each venue. Check with the venue before relying on anything here.

Where does the data come from?

Only from what each venue's operator publishes: the seating plan, and capacity statements on the operator's own pages and technical sheets. Addresses and coordinates come from LCSD's open data on DATA.GOV.HK. Nothing comes from ticketing or box-office systems, or from seat maps drawn by others.

How do you know the counts are right?

Every part of house is counted and must equal the total printed on the plan; the build fails if it does not. Where the plan has a text layer, every seat number is also matched against it one for one. Each file records the plan's version (its SHA-256), the sources and any conflicting figure found.

Why are some seats shown without a number?

Plans often print wheelchair spaces (W) and management seats (X) as boxes with no number. A number is filled in only when it follows exactly, for example two boxes between seats 20 and 23, or when the operator's technical sheet names them. Otherwise the box keeps no number, and the file says why.

What are management seats, and are they counted?

Seats the venue keeps for its own use, marked X on the plan. The printed totals leave them out, so the viewer does too by default; you can switch them on to see every box on the plan.

Why does a venue with an orchestra pit have no pit option?

A pit option is added only when the operator states how many seats the pit removes. Where the operator also names the rows, those are used; otherwise the rows are inferred as the front rows that give exactly that number, and marked as inferred. Where no figure is published, the pit is described in the sources but no seats are removed.

Does the planner keep what I enter?

No. The planner runs in your browser and sends nothing: categories, prices and names stay on the page and are gone when you close it, unless you save a plan file on your own device. A plan with names can be protected with a passphrase. See Privacy and usage.

Can I use the data in my own work, including commercially?

Yes. The seat lists are under CC BY 4.0: use them for any purpose, with credit, keeping the source lines in each file. The code is MIT. The planner's code is for noncommercial use unless agreed in writing, but using the planner on this site is free for anyone. None of this covers LCSD's own plans.

Is this project connected to LCSD or the venues?

No. It is an independent project, not affiliated with or endorsed by LCSD or any venue.

A venue is missing, or something looks wrong. What should I do?

Use the forms under Contribute: one for a correction, one to suggest a venue. Please link to the operator's published plan; ticketing data can't be used.
