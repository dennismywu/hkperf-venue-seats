# The Viewer shows only published data

The Viewer never applies a customisation, even when one is in the URL; customised versions appear only in the Customiser and the Planner, each labelled as the user's own. A screenshot or shared link of the Viewer must always mean "the published seat list", so that a user's edit (for example a wheelchair space agreed with the venue) is never mistaken for the venue's or this project's data. Applying customisations in the Viewer would have been simpler for sharing, and was rejected for that reason.
